# Дневник давления

Минималистичное Android-приложение на русском языке. Единственное оформление **Ясность**: светлый фон, шалфейный акцент и мягкие карточки. Переключателя оформления нет.

## Установка

**[Скачать APK 1.1.0](https://github.com/lleyn/pressure-diary/raw/refs/heads/main/outputs/pressure-diary.apk)**

Установочный файл также находится в [outputs/pressure-diary.apk](outputs/pressure-diary.apk). Это подписанная отладочная сборка для Android 8.0 и новее, с актуальным Android System WebView. Перенесите APK на телефон и откройте его. Если Android запросит разрешение установки, разрешите её для приложения, из которого открываете APK.

SHA-256: `56ac5df90daea46e6cccabac795db9ff349854bf519fe6eff774aa49eb3211fd`.

## Возможности

- Запись верхнего и нижнего давления, пульса, даты, времени и заметки.
- Изменение записи и удаление с подтверждением.
- История измерений; графики и средние значения за 7, 30 и 90 календарных дней.
- Раздел «Данные» с импортом, экспортом истории и информацией о хранении.
- Импорт совместимого CSV с предпросмотром, проверкой всех строк и пропуском повторов.
- Экспорт истории в CSV через системное окно сохранения Android.
- Работа без сети, аккаунта и разрешений. Приложение не запрашивает INTERNET.

Приложение начинает работу с пустым дневником. Демонстрационные значения есть только в примерах интерфейса. Автоматическая медицинская оценка показаний не выполняется.

Данные сохраняются локально в хранилище WebView. Удаление приложения или очистка его данных удаляет записи; для копии предусмотрены экспорт и импорт CSV. Автоматический backup Android отключён. Напоминания и облачная синхронизация в эту версию не входят.

## Импорт CSV

Откройте **Данные → Импортировать CSV**, выберите файл и проверьте предпросмотр. Нажмите **Добавить измерения**, чтобы сохранить новые записи. До подтверждения дневник не меняется; отмена не сохраняет ничего. Если хотя бы одна строка содержит ошибку, весь импорт останавливается с указанием номера строки. Исправьте файл и выберите его снова.

Поддерживаются CSV в **UTF-8**, с BOM или без него, размером до **1 МиБ (1 048 576 байт)** и до **5 000 измерений**. Разделитель определяется автоматически: `;`, `,` или табуляция. Поддерживаются кавычки, удвоенные кавычки и переносы строк внутри закавыченной заметки. Первая непустая строка должна содержать заголовки; порядок колонок может быть любым, регистр заголовков не важен.

| Данные | Допустимые заголовки | Формат |
| --- | --- | --- |
| Дата | `Дата`, `date` | `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД` |
| Время | `Время`, `time` | `ЧЧ:ММ` или `ЧЧ:ММ:СС` |
| Верхнее давление | `Верхнее`, `systolic`, `sys` | Целое число, 50–300 |
| Нижнее давление | `Нижнее`, `diastolic`, `dia` | Целое число, 30–200; меньше верхнего |
| Пульс | `Пульс`, `pulse` | Целое число, 20–250 |
| Заметка, необязательно | `Заметка`, `note`, `notes` | До 500 символов |

Вместо отдельных колонок даты и времени можно использовать `timestamp`, `at` или `datetime` с ISO 8601, например `2024-10-01T08:30:00+05:00`. Даты без часового пояса интерпретируются во временной зоне устройства. Даты в будущем не принимаются. Числовые границы ограничивают ввод данных и не являются оценкой здоровья.

```csv
Дата;Время;Верхнее;Нижнее;Пульс;Заметка
01.10.2024;08:30;120;80;68;Демонстрационная запись
02.10.2024;20:15;118;76;64;"Пример: отдых; вечер"
```

[Скачать пример CSV](tests/fixtures/import-valid.csv).

Повторы определяются по времени с точностью до минуты, верхнему и нижнему давлению, пульсу и заметке. Пропускаются совпадения с дневником и повторные строки внутри файла. Существующие записи не удаляются и не перезаписываются.

Экспорт приложения совместим с импортом. Для заметок, защищённых от интерпретации как формула таблицы, новый экспорт при необходимости добавляет служебную колонку `Формат заметки` (`escaped-v1` / `literal-v1`), чтобы восстановить исходный текст без потерь. Старые CSV без этой колонки также принимаются: апострофы заметок сохраняются как текст, а защита от повторов учитывает прежнее экранирование.

## Структура

- `android/app/src/main/assets/` — автономный интерфейс и логика приложения.
- `android/app/src/main/java/ru/pressurediary/app/MainActivity.java` — Android-оболочка, обработка системной кнопки «Назад», светлые системные панели и системный выбор файлов для импорта и экспорта CSV.
- `ui/preview.html` — интерактивный пример для просмотра в браузере; содержит демонстрационные данные.
- `ui/preview-shell.html` — исходный шаблон примеров.
- `tests/` — проверки валидации, календарных периодов, CSV и безопасного сохранения.

## Сборка

Для сборки без сети нужны JDK 17+, Android SDK Platform 36 и Build Tools 36.0.0:

```powershell
.\android\build-debug.ps1 -JdkPath 'C:\путь\к\jdk' -SdkPath 'C:\путь\к\Android\Sdk'
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`. Скрипт компилирует Java, ресурсы и DEX, подписывает APK, проверяет подпись и выравнивание. Локальный ключ отладочной сборки сохраняется в игнорируемой Git папке `android/.tooling/`; используйте тот же ключ, чтобы обновлять установленную сборку с сохранением данных.

Также подготовлен Gradle-проект с wrapper; при первом запуске `android/gradlew.bat assembleDebug` может потребоваться доступ к репозиториям Google и Maven.

Проверки:

```powershell
node --test tests/*.test.cjs
node tools/serve-preview.mjs
```

Предпросмотр: `http://127.0.0.1:8123`. Страница самого приложения: `http://127.0.0.1:8123/android/app/src/main/assets/index.html`.
