# Дневник давления

Минималистичное Android-приложение на русском языке. Единственное оформление **Ясность**: светлый фон, шалфейный акцент и мягкие карточки. Переключателя оформления нет.

## Установка

**[Скачать APK 1.0.1](https://github.com/lleyn/pressure-diary/raw/refs/heads/main/outputs/pressure-diary.apk)**

Установочный файл также находится в [outputs/pressure-diary.apk](outputs/pressure-diary.apk). Это подписанная отладочная сборка для Android 8.0 и новее, с актуальным Android System WebView. Перенесите APK на телефон и откройте его. Если Android запросит разрешение установки, разрешите её для приложения, из которого открываете APK.

SHA-256: `72dcd308e80c6b7d599fde5aab135034cb062138ccf1efbdc4d519f95f61b3e3`.

## Возможности

- Запись верхнего и нижнего давления, пульса, даты, времени и заметки.
- Изменение записи и удаление с подтверждением.
- История измерений; графики и средние значения за 7, 30 и 90 календарных дней.
- Раздел «Данные» с экспортом истории и информацией о хранении.
- Экспорт истории в CSV через системное окно сохранения Android.
- Работа без сети, аккаунта и разрешений. Приложение не запрашивает INTERNET.

Приложение начинает работу с пустым дневником. Демонстрационные значения есть только в примерах интерфейса. Автоматическая медицинская оценка показаний не выполняется.

Данные сохраняются локально в хранилище WebView. Удаление приложения или очистка его данных удаляет записи; для копии предусмотрен CSV. Автоматический backup Android отключён. Импорт CSV, напоминания и облачная синхронизация в эту версию не входят.

## Структура

- `android/app/src/main/assets/` — автономный интерфейс и логика приложения.
- `android/app/src/main/java/ru/pressurediary/app/MainActivity.java` — Android-оболочка, обработка системной кнопки «Назад», светлые системные панели и экспорт CSV.
- `ui/preview.html` — интерактивный пример для просмотра в браузере; содержит демонстрационные данные.
- `ui/preview-shell.html` — исходный шаблон примеров.
- `tests/` — проверки валидации, календарных периодов, CSV и безопасного сохранения.

## Сборка

Для сборки без сети нужны JDK 17+, Android SDK Platform 36 и Build Tools 36.0.0:

```powershell
.\android\build-debug.ps1 -JdkPath 'C:\путь\к\jdk' -SdkPath 'C:\путь\к\Android\Sdk'
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`. Скрипт компилирует Java, ресурсы и DEX, подписывает APK, проверяет подпись и выравнивание. Локальный ключ отладочной сборки сохраняется в игнорируемой Git папке `android/.tooling/`; используйте тот же ключ, чтобы обновлять установленную сборку с сохранением данных.

Также подготовлен Gradle-проект с wrapper; при первом запуске `android/gradlew.bat assembleDebug` может потребоваться доступ к репозиториям Google и Maven.

Проверки:

```powershell
node --test tests/*.test.cjs
node tools/serve-preview.mjs
```

Предпросмотр: `http://127.0.0.1:8123`. Страница самого приложения: `http://127.0.0.1:8123/android/app/src/main/assets/index.html`.

## Проверено

В исходной версии проверены размеры экрана 320 и 360 пикселей, валидация ошибочного ввода, создание записи, сохранение после перезагрузки, редактирование и отмена удаления без потери правок. В версии 1.0.1 оставлено оформление «Ясность»; проверены сохранность записей старого формата и отсутствие выбора оформления. Проверены структура, подпись и выравнивание APK.

Версия 1.0.1 устанавливается поверх предыдущей версии с сохранением записей: пакет приложения и ключ подписи прежние, код версии увеличен до 2. Старое сохранённое оформление игнорируется.

APK не запускался на физическом Android-устройстве или эмуляторе. Системное окно экспорта, Android-навигация и поведение клавиатуры на устройстве требуют такой проверки.
